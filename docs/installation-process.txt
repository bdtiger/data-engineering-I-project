2.1.3 Step 1.3: Install Java Development Kit
Hadoop is written in Java and requires the Java Development Kit (JDK) to run.
1. Update package lists:
sudo apt update
2. Install required packages:
sudo apt install openjdk-11-jdk-headless net-tools -y
3. Verify Java installation:
java -version
javac -version
You should see version 11.0.x for both.
2.1.4 Step 1.4: Set JAVA_HOME Environment Variable
Hadoop needs to know where Java is installed. We set the JAVA_HOME environment variable.
1. Add to system-wide environment:
sudo nano /etc/environment
7
Data Engineering I - 1TD169 Assignment A2
2. Add this line:
JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64/
Save and exit.
3. Apply to current session:
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64/
4. Verify:
echo $JAVA_HOME
ls $JAVA_HOME/bin/java



next installed hadoop
Step 1.5: Download and Install Hadoop
Now we will get Hadoop itself.
1. Navigate to your home directory:
cd ~
2. Download Hadoop 3.4.1:
Versions can be found on the releases page: https://hadoop.apache.org/releases.html
We use version 3.4.1, and use the binary download link (not source, not aarch64):
wget https://dlcdn.apache.org/hadoop/common/hadoop-3.4.1/hadoop-3.4.1.tar.gz
This downloads ~600 MB.
3. Extract the archive:
tar -xzf hadoop-3.4.1.tar.gz
This takes a while, and creates a hadoop-3.4.1 directory with all Hadoop files.
4. Verify installation:
./hadoop-3.4.1/bin/hadoop version

set the hadoop path
echo 'export HADOOP_HOME=~/hadoop-3.4.1' >> ~/.bashrc
echo 'export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin' >> ~/.bashrc
echo 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64/' >> ~/.bashrc
source ~/.bashrc
